# a-share-event-alpha

A 股事件驱动 + 传统因子的个人研究框架。核心原则是：**先用可交易的回测证明事件有 Alpha，再投入 NLP 抽取**。

> 仅用于个人研究，不构成任何投资建议，不对外提供荐股服务。

## 目标

- 核心—卫星组合：中证 1000 ETF 为核心，事件选股为卫星（起步占 30%）
- 基准：中证 1000 ETF；卫星部分相对基准的最大回撤 ≤ 20%
- 只做公告后第 2–20 个交易日的漂移窗口，收盘后出榜，次日开盘执行
- 合格线：卫星部分相对基准年化超额 3–6%（扣除成本、考虑一字板等可成交约束）

## 分期

| 阶段 | 内容 | 闸门 |
| --- | --- | --- |
| P0 数据底座 | 证券主数据、交易日历、不复权日线 + 复权因子、交易状态、财务 PIT、公告元数据、规则版本表 | 投毒测试通过；第二来源抽样核对 ≥ 99.9% |
| P0.5 Alpha 侦察 | 执行模拟器 + 结构化事件的事件研究 + Alpha158 基线 | ≥ 3 类事件可交易 CAR 扣成本后显著（FDR 10%） |
| P1 定向抽取 | 只抽 P0.5 证明有价值的事件参数 | 关键参数 precision ≥ 0.95，下游结论不变 |
| P2 融合与消融 | 因子 / +事件 / +NLP 参数 / +同行溢出 / embedding 对照 | 多数滚动窗口有正增量，DSR > 0.95 |
| P3 日报与影子 | 每日自动出榜、影子组合、数据健康检查 | 实时信号与回放 100% 一致 |

## 防泄漏约定

- 所有计算以 `as_of` 为参数，只读 `known_at <= as_of` 的数据
- 价格只存不复权价 + 复权因子，禁止前复权；涨跌停用不复权价判定
- 只知道日期的公告一律视为盘后发布，下一交易日可交易（见 `event_alpha.timeutil.tradable`）
- 涨跌幅、印花税、佣金等交易规则按日期版本化（见 `event_alpha.timeutil.rules`）
- 财务数据回测只用首次披露版本
- LLM 只抽取事实字段，不产生方向或重要性打分

## 目录

```text
src/event_alpha/
  adapters/    数据源适配器，只写 raw zone（保存原始响应）
  canonical/   raw -> canonical PIT 表
  timeutil/    交易日历、tradable_at、规则版本表
  events/      结构化 / 规则 / NLP 事件，事件簇与同行溢出
  factors/     传统因子
  sim/         执行模拟器：可成交掩码、一字板顺延、成本
  research/    事件研究、多重检验、消融
  recommend/   打分、过滤、分级、榜单快照
tests/
```

## 数据

仓库**不包含任何数据**。Tushare、AKShare 等数据源的许可通常限于个人非商业用途，请在本地自行获取，数据目录已在 `.gitignore` 中排除。
